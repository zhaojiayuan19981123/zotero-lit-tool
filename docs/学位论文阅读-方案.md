# 学位论文阅读 — 设计方案（v1.19.0）

> 状态：**已确认，正在实现** ｜ 目标版本 **v1.19.0**
> 这份文档留在仓库里，方便后续接着做（下一版可继续的项见 §9）。

---

## 0. 一句话

新增「学位论文阅读」独立模块：表格化书目管理（AI 读前 3 页填字段、支持分类）+ 面向超长文档的**检索增强 AI 对话** + 带**章节书签栏**的阅读器 + 面向大论文写作的素材沉淀（含对比阅读、关联大论文）。

---

## 1. 与「文献中心」的关系

- 左侧导航「研究工作」下新增 **学位论文阅读**，独立视图、独立数据文件 `data/theses.json`。
- **不动文献中心的任何既有行为**（阅读器默认走原来的 paper 模式，学位论文走 thesis 模式）。
- 复用：AI 对话持久化（`paper-chats.json` 按 id 存）、笔记（`paper-notes.json`）、上传/解析管线、模型路由与故障转移（含 v1.18.0 的本地端口 15721）。
- 差异：字段集不同、对话走检索增强通道、阅读器去掉划词/全文翻译、新增书签栏与自动进度、新增分类。

### 已确认的取舍

| 议题 | 决定 |
|---|---|
| 阅读进度 | **自动**：按实际读到的页码算，可手改；附带「回到上次位置」 |
| 评级 | **手点**（AI 给「建议评级 + 理由」，一键采纳，绝不自动写） |
| 分类 | **支持**：学位论文独立分类（`thesis-collections.json`），可拖动归类、批量归类 |
| 对比阅读 | **做** |
| 关联大论文 | **做** |
| 方案存档 | 存 `docs/`（本文件） |

## 2. 表格字段

默认 9 列（用户指定）：

| 列 | 来源 |
|---|---|
| 文献（PDF 上传） | 文件 |
| 阅读进度 | **自动**：已读页 / 总页数 → 未阅读 / 阅读中 / 已阅读，可手改 |
| 评级 | 用户点星（AI 只给建议） |
| 分类 | 用户归类（可拖动） |
| 学校 | AI 读前 3 页（封面 / 页眉） |
| 导入时间 | 系统 |
| 标题 | AI 读前 3 页 |
| 作者 | AI 读前 3 页 |
| 我的思考 | 用户手写（AI 永不覆盖） |
| 参考价值 | 用户手写（AI 永不覆盖） |

「字段配置」里可选打开（AI 一并提取，默认隐藏）：

学位类型（硕士 / 博士）、年份、专业、导师、关键词、摘要要点、一段话总结、研究问题、
理论框架、研究方法、数据来源与样本、主要结论、创新点、局限与不足、可借鉴之处、
章节结构概览、语料 / 代码 / 问卷是否公开。

AI 解析提示词要点：只喂前 3 页文本（约 6k 字符）→ 严格 JSON、缺失字段填空串、
学校与学位类型从封面识别、中文摘要。**`myThoughts` / `referenceValue` 两个用户字段不进提示词。**

## 3. 长上下文方案（本功能的核心）

**问题**：学位论文 150–400 页、纯文本 20–60 万字，远超任何模型窗口。既有 `/api/paper-chat`
是「头 75% + 尾 25% 截到 6 万字」，对单篇论文够用，对学位论文必然答不准——中间章节全丢。

**做法**：四层流水线（①②只跑一次并落盘缓存，③④每次提问毫秒级完成）。

### ① 结构层 `src/thesisOutline.js` — 章节识别

三级兜底：

1. **PDF 内嵌书签**（pdf.js `getOutline()`，最准，几乎零成本）；
2. **目录页解析**：识别「目录」页里的行（`1.1 xxx ...... 12`），取出标题与页码；
3. **标题正则启发式**：`第[一二三四五六七八九十]+章`、`^\d+(\.\d+){0,3}\s+`，
   加固定节名（摘要 / Abstract / 绪论 / 文献综述 / 研究设计 / 实证分析 / 结论 /
   参考文献 / 致谢 / 附录 / 攻读学位期间成果）。

产出 `outline: [{id, level, title, page, children}]` + 每章 `startPage/endPage`。
**一份数据两用**：既是阅读器左侧书签栏，也是检索时的章节归属。

### ② 索引层 `src/thesisIndex.js` — 分块建索引

- 按页取文本（`unpdf` 的 `mergePages:false`）；
- 按「章节 → 段落」切块，每块 500–800 字，带 `{chapterId, chapterTitle, page}`；
- 建稀疏倒排索引：中文 2-gram + 英文小写词（去停用词），配 **BM25** 打分
  （自实现，**零新依赖**）；
- 落盘 `data/thesis-index/<id>.json`。首次打开约 1–3 秒，之后秒开。

**不引入向量库 / embedding**：默认零依赖、零额外费用；中文 2-gram BM25 对「找章节、找概念、
找原话」这类学位论文高频问法足够。预留 `embedding` 钩子（默认关）。

### ③ 检索层 — 按提问定位

- 用问题（+ 最近一轮对话关键词）在倒排表上打分，取 top-8 段，附章节与页码；
- 两条保底规则：命中段集中在同一章时补该章首尾段；问题里出现「第 X 章 / 摘要 / 结论」
  等章节词时直接整章优先。

### ④ 组装层 — 上下文预算可控可见

四段拼装：

1. **档案卡**（约 1.5k，恒带）：标题 / 作者 / 学校 / 学位类型 / 专业 / 导师 + 研究问题、
   理论框架、方法、数据、结论、创新点 + **章节目录树（带页码）**；
2. **当前位置**（约 6k，恒带）：明确标注「用户当前在第 47 页《第三章 3.2》」，附当前节正文；
3. **检索命中**（约 15k）：top-8 段，每段带 `【第 3 章 3.2 · p.47】`；
4. **最近 8 轮对话**。

顶部给「上下文预算」三档：**精简 20k / 标准 40k / 充裕 80k**，按所选模型自动给默认值、可手改。

提示词硬性要求：引用必须写 `【第 3 章 3.2 · p.47】`；检索不到就回答「正文里没检索到」，
禁止编造。**回答里的出处标注可点击，直接跳到 PDF 该页。**

## 4. 阅读模式与书签栏

- **顶部**：返回、文件名、页码跳转、适宽 / 缩放、当前位置「第 47 页 · 第三章 3.2」、笔记模式。
- **左侧书签栏**（可折叠，默认展开）：
  - 搜索框（过滤章节 / 书签）+「＋ 添加书签」；
  - 章节树：层级缩进、页码右对齐；**当前章节随滚动自动高亮并滚到可见**；
  - 我的书签单独一组置顶（页码 + 一句备注），可编辑 / 删除；
  - 点击跳页；悬停出现「收藏为书签」「复制引用」。
- **右侧面板只留两个页签**：「解析结果」「AI 对话」——划词翻译、全文翻译在学位论文里**不出现**。
  - 对话栏含：模型选择器（沿用顶栏）、「附上本节正文」开关、上下文预算档位、出处可点的回答。
- **笔记模式保留**，三栏改为「原文 PDF ｜ AI 对话 ｜ 笔记」。
  中间栏由「划词翻译」换成对话：划词后自动作为引用塞进提问框（"关于这段：…"）。

## 5. 面向写作与资料积累

**P0（本版必做）**

1. **阅读位置与进度自动记录**：打开回到上次位置，进度按页码自动算。
2. **章节速读**：对当前章节一键生成「研究问题 / 方法 / 结论 / 对我的启示」四段，直接追加进笔记。
3. **摘录素材库**：选中文字 →「加入素材库」，存 `thesis-quotes.json`，带出处（论文 / 章节 / 页码）；
   一键复制成规范引注与 Markdown 引用块；可按论文 / 章节 / 标签筛选、导出 Markdown。
4. **综述条目生成**：把一篇学位论文压成「理论 / 方法 / 数据 / 结论 / 局限」结构化条目，一键复制。
5. **出处跳转**：对话 / 笔记 / 素材里所有 `p.N` 均可点击跳页。

**P1（本版一并做）**

6. **对比阅读**：勾选 2–5 篇学位论文 → 生成对比表（研究对象 / 理论 / 方法 / 样本 / 结论 / 创新点），
   可导出 Markdown。
7. **答辩问答演练**：AI 从该论文出 10 个答辩问题 + 带页码的参考要点。
8. **与我的大论文关联**：从「论文进度 → 大论文」里选一篇关联；问答时额外带上
   「我的大论文框架 + 当前阶段」，直接回答「这章的方法能不能用在我的第 4 章」。

**P2（留待下版）**

9. 与「Markdown 笔记」标签体系打通（`thesis/<论文>/<章节>`）。
10. 多篇学位论文交叉检索（"这三篇里谁用了计划行为理论"）。

## 6. 存储与接口

**新增模块**：`src/thesisFields.js`、`src/thesisOutline.js`、`src/thesisIndex.js`、
`src/thesisContext.js`（服务端编排）；前端 `public/thesis.js` + `public/thesis.css`。

**新增数据文件**（都进 `ALL_DATA_FILES`，自动有备份/迁移/导出）：

| 文件 | 内容 |
|---|---|
| `theses.json` | 学位论文记录（含分类 id、进度、AI 字段、阅读位置） |
| `thesis-collections.json` | 学位论文分类 |
| `thesis-quotes.json` | 摘录素材库 |
| `thesis-index/<id>.json` | 章节索引缓存（不备份，可重建） |

**复用**（按 id 存，零迁移）：`paper-chats.json`（对话）、`paper-notes.json`（笔记）。

**新路由**：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET / POST | `/api/theses` | 列表 / 新建 |
| PATCH / DELETE | `/api/theses/:id` | 修改 / 删除（只允许改白名单字段） |
| POST | `/api/theses/:id/attachment` | 上传 PDF（复用 multer） |
| POST | `/api/theses/:id/parse` | AI 读前 3 页填字段 |
| GET / POST | `/api/thesis-collections` | 分类列表 / 新建 |
| PATCH / DELETE | `/api/thesis-collections/:id` | 分类改名 / 删除 |
| POST | `/api/theses/:id/index` | 建章节索引（SSE 报进度） |
| GET | `/api/theses/:id/outline` | 书签树 |
| GET | `/api/theses/:id/chat` | 检索增强问答（SSE） |
| POST | `/api/theses/:id/summarize` | 章节速读 / 综述条目 / 答辩题（SSE） |
| POST | `/api/theses/compare` | 对比阅读（SSE） |
| GET / PUT | `/api/theses/:id/quotes` | 素材库 |
| GET / PUT | `/api/thesis-bigpaper` | 关联的大论文信息（框架 + 阶段） |

全部走同一套模型路由与故障转移，v1.18.0 的本地端口（15721）自动能路由到这些新模型。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 扫描版学位论文没有文字层 | 解析前先探测文本量，不足则明确提示「需要带 OCR 文字的 PDF」，不静默失败 |
| 没有内嵌书签也没有目录页 | 走标题正则三级兜底；再不行退化成「每 10 页一块」，书签栏给出页码提示 |
| 索引构建慢 | 建索引过程用 SSE 报进度（第 n/N 页），可关闭窗口后台继续；完成后弹提示 |
| 上下文仍装不下 | 预算三档可调 + 命中段落按分数截断，并在回答上方显示「本次用了 X 字上下文」 |
| 与文献中心互相干扰 | 数据文件、路由、字段、前端模块全部独立；阅读器是独立实现，不共用 `pr` |
