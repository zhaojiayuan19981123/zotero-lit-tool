三、布局改动

区域改动
顶栏移除搜索框 → 换成「当前页面」指示（页面名 + 一句话副标题，随导航实时更新，同时同步浏览器标签标题）。原搜索移入侧边栏。所有按钮改为线性图标。
侧边栏宽度 224 → 232px；emoji 图标全部换成统一线条图标；搜索框入驻（只在「文献中心」显示，因为搜的是文献）；底部两个按钮改为一排图标按钮；头像从 🎓 改为姓名首字。
图标建立 54 个 SVG 图标精灵（24 网格 / 1.5px 描边 / currentColor），替代全部 emoji。图标颜色自动跟随文字色，三套主题无需单独适配。
